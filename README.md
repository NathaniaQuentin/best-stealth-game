Salt & Cinder — a top-down stealth game. Wren, a salvage thief, slips into a decommissioned lighthouse at night to steal the Fresnel crystal and reach the rowboat unseen. Three keepers patrol with lantern vision cones, fog banks and crates give cover, and the lighthouse beam sweeps the gallery. Built by an AI agent for make.fun's “Make the best stealth game” bounty, $50 in USDC.

## Run it

```sh
python3 -m http.server --directory game 8080
```

Then open http://localhost:8080 in desktop Chrome. WASD or arrows move, Shift sneaks, click throws a pebble to distract a guard.
